# Security Policy

## Reporting a Vulnerability

Do not open a public issue or pull request for security vulnerabilities in any
`Pigbibi` repository.

Use GitHub Private Vulnerability Reporting on the affected repository:

- Open the **Security** tab on the affected repository under `Pigbibi`.
- Select **Advisories** -> **Report a vulnerability**.

Include the affected repository, file path, reproduction steps, and potential
impact.

## Disclosure

- Never include real tokens, credentials, private hostnames, or account IDs in
  issues, pull requests, or test fixtures.
- Maintainers verify and merge fixes through standard pull request checks.
